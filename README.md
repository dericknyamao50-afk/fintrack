# Fintrack 💰

A full-stack personal finance tracker. Track income, expenses, and see where your money goes.

## Features
- Add income & expenses
- Categorize transactions
- Dashboard with totals & history
- Clean, fast UI

## Tech Stack
- **Frontend:** React + Vite
- **Backend:** Python Flask
- **Database:** SQLite
